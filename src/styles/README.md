# 봉인 제단 스킨 — 절 묶음

`src/ui-skin.css` 한 장(13,827줄)을 **절 경계 그대로** 쪼갠 결과다. 한 줄도
다시 쓰지 않았다 — 순서 보존 이동만 했다. 빌드 CSS 는 분할 전후 바이트가
같다(같은 내용 해시 `index-BtetNeVP.css`).

## 왜 쪼갰나

새 절은 언제나 파일 **끝에 덧붙는** 구조였다. 그래서 병렬 트랙 두 개가
서로 다른 화면을 손봐도 매번 같은 자리(EOF)에서 충돌했고, 병합할 때마다
절 순서를 손으로 봉합해야 했다. 파일을 나누면 새 절은 **새 파일**로 가므로
그 충돌이 사라진다.

## 순서 규칙

CSS 는 캐스케이드다. **아래에 있을수록 세다.** 배럴 `ui-skin.css` 의
`@import` 순서가 곧 옛 파일의 위→아래 순서이며, 그것이 정본이다.
파일 이름의 숫자 접두는 그 순서를 눈으로 확인하기 위한 것이지,
번호가 순서를 만드는 것이 아니다 — 순서를 만드는 것은 배럴뿐이다.

`styles.css` → `ui-skin.css`(배럴) 순으로 로드된다는 큰 골격도 그대로다.
`main.ts` 가 그 두 줄을 순서대로 import 한다.

### 새 절을 더할 때

1. `src/styles/` 에 새 파일을 만든다. 이름은 `번호-주제.css`.
2. 배럴 `ui-skin.css` 에 `@import "./새파일.css";` **한 줄**을 더한다.
3. 그 한 줄을 어디에 넣을지는 아래 "뒤에 있어야 하는 것들"을 따른다.

기존 파일 끝에 덧붙이지 말고 새 파일을 만들어라. 그것이 이 구조의 전부다.

### 뒤에 있어야 하는 것들

맨 뒤 두 묶음은 자리가 고정이다. 앞으로 옮기면 조용히 깨진다.

- **`900-fb6-calm.css`** — 자극 완화(FB6)와 `차분한 화면` 게이트. 맥동·플래시를
  **끄는** 절이라, 그것을 켜는 모든 절보다 뒤에 있어야 이긴다. 앞으로 가면
  중간 절의 애니메이션이 되살아난다.
- **`910-ssb-title.css`** — 축소 배율 글자 보정(SSB). 앞선 절들이 정한 글꼴·
  그림자를 축소 구간에서만 되덮는 마지막 보정이라 맨 끝이 제자리다.

그 사이 순서(94~98 → R99 → FBT-1 → FB7 → FB1 → FB4 → FB3)도 분할 전 파일
순서 그대로다. 절끼리 특정도가 비슷한 곳이 있어 순서를 바꾸면 승자가 뒤집힌다.

## 9슬라이스 — 그림을 먼저 보고, 화면 대조로 지운다

액자·띠·쪽지는 `border-image` 를 **절대 위치 `::before`** 에 건다
(`700-nineslice.css`). 요소 자신에 걸면 `border-width` 가 상자를 키워 고정
격자를 밀어낸다 — 예전에 9슬라이스를 통째로 걷어야 했던 이유가 그것이었다.
`border-image-width` 는 가로세로 **같은 배율**로 적어야 모서리가 안 찌그러진다.

자산의 잘라 쓸 값(slice)은 **문서를 믿지 말고 그림을 뜯어 보고 정한다.**
납품 문서가 틀린 적이 두 번 있다.

| 자산 | 판정 | 비고 |
| --- | --- | --- |
| `nav-rail-empty-381x89-v2` | 10 14 맞음 | 모서리 걸쇠 안쪽에 정확히 떨어진다 |
| `status-strip-empty-333x43-v2` | 10 14 맞음 | 깎인 모서리 바로 바깥 |
| `boss-alert-ribbon-880x64-v1` | 14 60 맞음 | 가로줄이라 가로 늘림에 강하다 |

| `card-frame-*-600x400-v1` | 9슬라이스 **아님** | 좌우가 세로 축이고 매듭이 감겨 있다. 통짜로 늘려 쓴다(`740-jipjaso-skin.css`) |

죽은 규칙을 지울 때는 **사진 대조**로 판정한다. 지우기 전후로 같은 화면을
찍어 화소를 견주면, "덮이니까 죽었겠지"라는 추측이 틀렸을 때 바로 잡힌다.
실제로 이 방식이 `gap: 0`(33절에만 있던 값)과 상태 띠 배경을 잡아냈다.
찍을 때 애니메이션은 반드시 멈춰 세워라 —
`*,*::before,*::after{animation:none !important;transition:none !important}`
를 주입하지 않으면 탭 강조 연출의 위상 차이가 200화소짜리 가짜 차이로 잡힌다.

## 주의

- 파일 안의 절 번호(`절 47.`, `R7-25.` 등)는 **역사적 이름**이다. 파일 이름과
  일치하지 않아도 정상이며, 다른 절 주석이 그 번호로 서로를 가리키므로
  고쳐 쓰지 않는다.
- `url()` 은 모두 `/assets/…` 뿌리 절대 경로라 파일이 옮겨 가도 그대로 푼다.
  새 절에서도 상대 경로를 쓰지 마라 — 쓰면 `src/styles/` 기준으로 풀린다.
- vite 는 빌드에서 `@import` 를 인라인하므로 산출 번들은 한 장짜리 시절과
  같다. 요청 수가 늘지 않는다.
