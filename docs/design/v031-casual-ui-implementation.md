# v0.31 캐주얼 UI 결정 기록

> 기록 시점의 명칭이다. 여기서 `캐주얼`은 현재의 `별승급 진법`, `전략`은 `자형연성 진법`이다. 3체 조합 규칙도 이후 `3기 전소모 → 같은 오행 다음 별 무작위 획득`으로 바뀌었다. 현행 규칙은 `GAME_DESIGN.md`를 따른다.

## 기준 이미지

- `v031-before-title-1280x720.png`: 기능 체크포인트의 실제 시작 화면
- `v031-before-casual-fusion-1280x720.png`: 기능 체크포인트의 실제 3체 조합 화면
- `v031-casual-fusion-ui-concept.png`: 인게임 조합 공방 방향 시안
- `v031-casual-mode-flow-board.png`: 모드 선택부터 결과까지의 씬 흐름 보드

생성 시안은 시각 방향만 참고한다. 시안 속 임의 한자·획수·별 구간·수치는 런타임 데이터가 아니며, 실제 구현은 `src/data/cheonjamun-strokes.json`과 게임 엔진의 계산값만 표시한다.

## 구현 결정

1. 캐주얼의 `3체 조합` 탭을 열 때만 공방이 전장 오른쪽 일부로 확장된다. 캔버스 비율을 찌그러뜨리지 않고 전장의 약 60%를 계속 볼 수 있게 한다.
2. 선택 순서를 `① 남길 본체 KEEP → ② 소모 재료 USE → ③ 소모 재료 USE → 승급 결과`로 고정한다.
3. 선택 슬롯에도 후보 목록과 같은 자령 이미지, 한자, 현재 별, 자연 별, 획수, 전장·인벤 위치, 잠금 상태를 표시한다.
4. 본체는 청록·금색, 소모 재료는 주홍·잿빛으로 분리한다. 색만으로 구분하지 않도록 KEEP·USE 텍스트를 함께 쓴다.
5. 속성별 자동조합은 즉시 실행 버튼이 아니라 확인창을 여는 버튼이다. 잠금·농축·목표·성어 보호와 소모 목록을 확인한 뒤 실행한다.
6. 자연 별 획수표는 8칸 각인 범례로 압축한다. 정확한 구간은 1★ 1~8획, 2★ 9~11획, 3★ 12~13획, 4★ 14~15획, 5★ 16~17획, 6★ 18~19획, 7★ 20~21획, 8★ 22~29획이다.
7. 브라우저 기본 스크롤바를 쓰지 않고 짙은 각인 트랙과 황동 손잡이로 통일한다.
8. 800px 이상 데스크톱·소형 노트북은 16:9 게임 프레임 전체를 한 화면에 유지하고 웹 문서 스크롤을 만들지 않는다. 800px 미만 또는 높이 620px 이하에서는 공방 확장을 해제하고 기존 패널 안에 넣는다.

## 흐름 계약

`모드 선택 → 첫 자령 소환 → 첫 오행진 무료 개방 → 같은 오행·같은 현재 별 3기 선택 → KEEP/USE 확인 → 1성 승급·전투 → 100웨이브 결과 → 재도전`

자연 별은 획수 기반 최초 희귀도이고, 현재 별은 그 런에서의 조합 성장이다. 두 값은 합쳐 쓰지 않으며 최고 웨이브 기록도 전략·캐주얼 모드별로 분리한다.
