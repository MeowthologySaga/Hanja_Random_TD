## 재현 방법 (v3)

```bash
# 빈 작업 디렉터리에서
mkdir -p fonts && cp <사용자 폰트>/NotoSansKR-Bold.ttf fonts/
node <repo>/.codex_tmp/demo/assemble-v3.mjs   # cwd 가 build 디렉터리여야 한다
```

- 편집 스크립트: `.codex_tmp/demo/assemble-v3.mjs` (장면·배속 세그먼트와 자막
  문안·타이밍이 데이터로 들어 있다). 생성물 사본: `.codex_tmp/demo/subs-v3.ass`,
  `.codex_tmp/demo/timeline-v3.json`
- S4 재촬영: `.codex_tmp/demo/record-s4dev.mjs` — vite dev 서버(DEV QA 핸들 필요)를
  띄우고 `node record-s4dev.mjs CHEONJA-DEMO http://127.0.0.1:<port>` 실행.
  성어 재료 3기를 ①②③ 줄에, 마지막 1기를 보관고에 지급한 뒤 보관고→배치→발동을
  사람 손 마우스로 진행하고 `demo-scenes-raw/scene-04-v3.webm` 을 남긴다.
- 나머지 장면의 컷 좌표·원본은 v2 README(git 이력) 및 `demo-scenes-raw/scene-0N.webm` 그대로.

> 저장소 크기 주의: submission/ 영상(mp4 3본 + webm)이 무겁다. 커밋 전에 LFS 를
> 쓰거나 백업본·원본 webm 은 빼는 편이 좋다.
