# 천자진 — 라이브 시연 각본 (본선 엘리베이터 피칭용)

작성: 2026-08-27. 근거: `src/ui/tutorial.ts`(수련장 8걸음 각본) · `src/ui/tutorial-script.ts`(고정 시드 `TUTORIAL`, 확정 성어 `이심전심`) · `.codex_tmp/demo/record-s4dev.mjs`(백업 레시피) · `handoff/LOG.md`(데모 영상 v3).

시연 무대: **라이브 배포판** https://meowthologysaga.github.io/Hanja_Random_TD/
시연 장치: **수련장 모드** — 타이틀(3D 서재) 왼쪽 서갈피 열 아래 `수련장` 목패(부제 "처음이라면 여기부터", 八 인장).

수련장이 시연 장치로 안전한 이유(리허설 때 그대로 확인됨):

- **고정 시드 `TUTORIAL`** — 첫 소환·개방 진·지급물이 언제 열어도 동일. 리허설과 본번이 같은 진행.
- **soft-lock** — 각 걸음이 짚어주는 조작만 클릭 가능. 엉뚱한 곳을 눌러도 말풍선이 흔들릴 뿐 진행이 깨지지 않음. 단축키(소환·배속·도감 등)도 전부 잠김.
- **준비 시간 13초 고정** — 각본 밖에서 웨이브가 저절로 시작되지 않음. 발표자가 말을 얼마나 길게 해도 시간 압박 없음.
- **7걸음 성어 확정 체험** — 네 글자를 각본이 지급하고 1번째 글자는 미리 놓아줌. ②→③→④ 금색 점선 칸만 순서대로 클릭하면 **봉인 발동이 반드시** 나옴.
- 패배는 이론상 없음(완화 스케일). 만에 하나 지면 수련장이 스스로 처음 걸음부터 재정비함.

## 3. 백업 1 — QA 핸들 성어 즉석 발동 레시피

수련장 진입이 어떤 이유로든 막히거나, **본편 화면에서 성어 발동만 즉석으로** 보여야 할 때. `.codex_tmp/demo/record-s4dev.mjs`(데모 영상 v3의 S4 장면 녹화 스크립트)에서 추출·검증된 경로다.

**전제(중요)**: QA 핸들 `window.__HANJA_CTX_QA__` 는 **dev 빌드 전용**이다(`src/ui/app-context.ts` — `import.meta.env.DEV` 게이트). **라이브 Pages 배포판에서는 동작하지 않으므로**, 발표 전에 로컬 dev 서버를 반드시 백업으로 띄워 둔다.

1. 사전 기동(발표 전): 저장소에서 `npm run dev` → http://127.0.0.1:4437/ 탭을 백그라운드에 준비.
2. 주소창: `http://127.0.0.1:4437/?seed=CHEONJA-DEMO&mode=casual` (KR·별승급 진법 고정 시드 런).
3. 코치마크·1회성 힌트가 시연을 가리지 않게, 콘솔에서 먼저 1회 실행 후 새로고침:
   ```js
   localStorage.setItem("hanja-td:coach-seen-v1", "1");
   localStorage.setItem("hanja-td:early-hint-v1", "1");
   for (const k of ["stroke-star","midstar-open","research-open","first-fuse","essence"]) localStorage.setItem(`hanja-td:hint:${k}:v1`, "1");
   localStorage.setItem("hanzi-rtd-auto-place-summons", "true");
   ```
4. `[시작하기]` → `[기본 소환]` 1회 실제 클릭(진 무료 개방 연출을 자연스럽게 확보).
5. 콘솔에 아래 스니펫 붙여넣기 — **추적 성어 4자 중 3자를 한 줄에 배치하고, 마지막 1자를 보관고에** 넣는다:
   ```js
   (() => {
     const qa = window.__HANJA_CTX_QA__; const e = qa.engine;
     const idiom = e.currentIdiomTarget();
     if (!idiom) return "성어 목표 없음 — 목표 탭에서 성어를 지정";
     const chars = [...idiom.chars];
     const f = e.state.unlockedFormations[0];
     const startCell = f * 16;
     const cells = [0, 1, 2, 3].map((c) => startCell + 4 + c); // 둘째 줄
     const occupied = new Map(e.state.towers.map((t) => [t.cell, t]));
     for (const cell of cells) {
       const home = occupied.get(cell);
       if (home) for (let alt = startCell; alt < startCell + 16; alt++) {
         if (cells.includes(alt)) continue;
         if (!e.state.towers.some((t) => t.cell === alt)) { home.cell = alt; break; }
       }
     }
     const defs = chars.map((c) => e.catalog.definitions.get(c));
     for (let i = 0; i < 3; i++) {
       e.state.towers.push(e.createTower(defs[i], cells[i]));
       if (!e.state.discoveredChars.includes(chars[i])) e.state.discoveredChars.push(chars[i]);
     }
     const last = e.createTower(defs[3], -1);
     e.state.inventoryTowers.push(last);
     if (!e.state.discoveredChars.includes(chars[3])) e.state.discoveredChars.push(chars[3]);
     e.state.gold = Math.max(e.state.gold, 57);
     qa.runInventoryRenderKey = ""; qa.selectedRenderKey = "";
     qa.evolutionRenderKey = ""; qa.activeIdiomsRenderKey = "qa-reset";
     return `준비 완료 — ${idiom.chars} (${idiom.reading}), 마지막 글자 ${chars[3]} 는 보관고`;
   })();
   ```
6. 화면 조작으로 발동(여기부터는 전부 실제 UI — 관객에게는 정상 플레이로 보임):
   - `[목표]` 탭 → 성어 목표 모드(우측에 성어 카드 = 도해 역할). 전장에 ①②③ 순번 인장과 ④ 금색 점선이 떠 있는지 확인.
   - `[보관고]` 탭 → 보관고 프레임 열기 → 마지막 글자 카드 선택 → `[배치]` → **점선 ④칸 클릭 → 봉인 발동**.
7. 발동 후 활성 성어 칩에 마우스를 올려 유지형 보너스 표기를 보여 주며 마무리.

주의: 스니펫은 데모 연출 전용 상태 주입이다. 시연 멘트에서 "본편 화면"이라고만 하고, 미리 준비한 판이라는 점을 굳이 숨길 필요는 없다("성어 장면만 바로 보여드리기 위해 준비한 판입니다").

## 5. 리허설 체크리스트

발표 전날 + 발표 직전 2회 점검.

**화면**
- [ ] 브라우저 줌 100% (Ctrl+0). OS 디스플레이 배율도 확인 — 게임은 1280×720 고정 무대를 균일 스케일하므로 어떤 창에서도 같은 그림이지만, 줌이 걸리면 흐릿해진다.
- [ ] 창 최대화 또는 F11 전체화면. 빔 해상도가 16:9가 아니면 레터박스가 생기는 것이 정상 — 미리 봐 둘 것.
- [ ] 발표 머신에서 실제 클릭 리허설 1회(수련장은 고정 시드라 본번과 동일 진행이 보장됨).

**소리**
- [ ] 회장 스피커 연결 후 볼륨 테스트 — 게임 오디오는 첫 클릭에서 언락됨(타이틀 클릭 한 번이면 BGM 시작).
- [ ] 음소거 상태 아님 확인(게임 내 M 토글·OS 볼륨 둘 다).
- [ ] OS 알림·메신저 방해금지 모드.

**시드·저장 상태**
- [ ] 수련장은 시드 `TUTORIAL` 고정 — 별도 시드 조작 불필요.
- [ ] 시연 전 `localStorage.removeItem("hanja-td:tutorial-complete-v1")` 실행(또는 시크릿 창 사용) — 수련장 목패의 첫 방문 맥동을 복원해 "처음이라면 여기부터"가 살아 있게.
- [ ] 시크릿/새 프로필 창 사용 권장 — 코치마크·힌트·설정 잔재 없이 관객이 볼 첫인상 그대로.
- [ ] 최신 배포 확인: 라이브 URL 하드 리로드(Ctrl+Shift+R) — 서비스 워커가 문서를 network-first로 갱신하지만 발표 직전 한 번 강제 갱신.

**백업 준비**
- [ ] 로컬 dev 서버 기동 상태(`npm run dev`, 127.0.0.1:4437) — QA 핸들 백업 경로용.
