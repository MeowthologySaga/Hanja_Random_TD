# 한자 운명진 v0.33

실제 한자 조합식의 `전략 조합전`과 실제 획수 희귀도의 `캐주얼 8성전`으로 10장·100웨이브를 막는 한자 랜덤 타워 디펜스입니다. 기존 v0.1과 원본 핸드오프 ZIP을 덮어쓰지 않은 별도 Git 프로젝트입니다.

## 바로 실행

Windows 로컬 핸드오프에 `개발서버_실행.exe`가 포함되어 있다면 더블클릭합니다. 공개 소스 저장소에는 생성된 EXE를 넣지 않으므로 아래 명령으로 실행하거나 런처 소스를 직접 빌드합니다. 서버가 이미 실행 중이면 런처는 중복으로 띄우지 않고 브라우저만 엽니다.

런처 소스는 `tools/dev-server-launcher/Program.cs`에 있으며 `tools/dev-server-launcher/build.ps1`로 단일 EXE를 다시 만들 수 있습니다. 로컬 생성 파일이라 코드 서명은 포함하지 않았습니다.

명령줄로 실행하려면:

~~~powershell
npm.cmd ci
npm.cmd run dev
~~~

브라우저에서 http://127.0.0.1:4437/ 을 엽니다.

## 이번 버전의 핵심

- Suno로 제작한 무보컬 BGM 6곡(메인 메뉴·초반·중반·후반·보스·100웨이브 최종전)과 핵심 행동 SFX 12종을 추가. 브라우저 정책에 따라 첫 조작 후 메뉴곡을 재생하고 전투곡으로 3초 크로스페이드하며, 보스 진입 8초 지연·종료 5초 유예, 개별 BGM/SFX 음량·음소거 저장, 반복 타격 합성음의 중복 제한을 함께 적용
- 천자문 자령 1,000개 런타임 이미지를 보존된 생성 원본에서 직접 다시 추출. 전투·상점·도감이 같은 256px 자산을 사용해 128px 미리보기를 재확대하던 흐림을 없애고, 확대 0건·최소 투명 여백 12px·자홍색 경계 제거를 검증
- 시작 화면에서 `전략 조합전`과 한국 천자문 전용 `캐주얼 8성전`을 선택. 모드별 최고 웨이브 기록은 서로 분리
- 캐주얼은 Unicode 17.0.0 Unihan `kTotalStrokes`의 실제 획수로 천자문 1,000자의 기본 별을 결정: 1★ 1~8획 332자, 2★ 9~11획 252자, 3★ 12~13획 167자, 4★ 14~15획 105자, 5★ 16~17획 68자, 6★ 18~19획 33자, 7★ 20~21획 25자, 8★ 22~29획 18자
- 캐주얼에서는 천자문 1,000종이 모두 직접 등장하고, 같은 오행·같은 현재 별 자령 3기 중 남길 본체 1기와 소모 재료 2기를 명시적으로 골라 최대 8★까지 승급
- 3체 조합 전에 남는 본체·사라지는 재료·전장/인벤 위치·잠금·보호 경고를 확인. 잠긴 재료는 소비 불가이고 본체의 위치·잠금·농축은 유지
- 木·火·土·金·水별 자동조합은 인벤토리의 약한 중복을 우선 사용하고 잠금·농축·목표·성어·일반 합성 재료를 기본 제외하며, 실행 전에 전체 소모 목록을 다시 확인
- 캐주얼 1★는 기본 공격만, 2★부터 의미·역할 기술을 해금. 1~8★ 피해 배율은 1.00 / 1.38 / 1.86 / 2.48 / 3.25 / 4.20 / 5.35 / 6.70이며 별마다 공격 대기시간 2% 감소·사거리 +3
- KR 원본 1,000자와 천자문 누락 보충 `烈` 1자, JP 2,136자, CN 3,500자를 지역 ID로 분리
- 한국 천자문 직접 소환 풀과 플레이어용 이미지 도감을 1,000종 전체로 확장하고, 기존 360종의 상세 기록은 그대로 보존
- 천자문 의미와 기존 오행이 충돌한 18자는 원본 JSON을 보존한 채 KR 전용 의미 기반 타입 오버레이 적용
- 첫 4회는 목표·사자성어 온보딩용 기존 가중치를 유지하고, 5회째부터 신규 직접 자령을 동등 편성해 미발견 한자를 우선하는 중복 억제 가중치 적용
- 정확히 대응하는 한자는 해당 자령을, 나머지 글자는 같은 오행의 기존 자령 중 하나를 결정론적으로 배정
- 자령 머리 위와 선택 카드에 현재 한자와 짧은 훈음을 표시하고, 부수는 공부 모드·도감에 유지
- 설정의 `공부 모드`로 전환하면 v0.7의 큰 한자 원형과 짧은 읽기 표시를 그대로 사용하며 선택은 브라우저에 저장
- 북·서·중앙·동·남에 정확한 4×4 오행진 5개를 배치하고, 열린 진 없이 시작해 첫 소환과 같은 오행진을 무료 개방한 뒤 나머지를 18·32·52·78엽전에 원하는 순서로 개방
- 따뜻한 한지 바탕 위에 다섯 진과 먹빛 경로를 동일한 200×200 정사각형 모듈로 맞추고, `바깥 십자 외곽 1바퀴 → 중앙 정사각형 1바퀴`의 규칙적인 이중 사각 순환 사용
- 경로의 각 직선 중앙에는 붓끝형 겹화살표를 고정하고, 젖은 먹방울 10개와 번짐 꼬리가 같은 방향으로 반복 순환해 다음 이동 구간을 예측 가능
- 한지 바탕은 정적 CSS 합성 레이어에 고정하고 지도만 독립적으로 확대·축소·패닝해 프레임별 재표본화 깜박임과 최소 72% 축소의 검은 빈 공간을 함께 방지
- 북·서·중앙·동·남 오행진은 옅은 수묵·담채 카드로 정리하고 네 출구는 주홍색 `出` 인장으로 표시
- 북·동·남·서 네 출구가 같은 단일 순환로를 공유하며 새 적은 네 출구에서 차례대로 균등 출현
- 적은 한 바퀴 뒤 사라지거나 결계를 깎지 않고 처치될 때까지 계속 순환하며, 활성 적 80체 또는 보스 제한시간 초과만 게임오버 조건으로 사용
- 일반 웨이브는 마지막 적 소환 후 20초 카운트다운이 끝나면 잔존 적을 유지한 채 다음 웨이브가 합류해 미처리 적 누적 자체가 패널티로 작동
- 기존 내부 260% 크기를 새 기본 100%로 재정의, 휠 확대·축소 약 28%~200%, 빈 곳 좌클릭 또는 휠 클릭 드래그 패닝, 확대 상태 선택·드래그 좌표 보정, 왼쪽 아래 100% 중앙 초기화 버튼 제공
- 자령 머리 위 라벨 높이와 한자·훈음 글자 크기를 키워 기본 배율에서도 획이 뭉개지거나 읽기가 잘리지 않도록 보강
- 우측 상단에서 1×·2×·3× 게임 배속 순환
- 설정의 `뽑기 후 자동 배치`는 기본 ON이며, OFF일 때 새 자령을 이번 판 전용 대기 인벤토리에 보관. 자동 배치가 켜져 있어도 전장 80칸이 차면 소환을 계속 허용하고 새 자령을 런 인벤토리에 자동 보관
- 균형·탐색·계보·중복 수집 목적 소환을 선택할 수 있으며, 계보 소환은 12회마다 목표·성어 단서를, 30회마다 개방된 목표 한자를 확정
- 단일 소환은 3.8초간 큰 결과 카드를 표시하고 화면 아무 곳을 누르면 즉시 닫힘. 소환·탭 버튼을 눌렀다면 결과창을 닫는 동시에 해당 조작도 이어서 실행. 10연 소환은 한자·훈음·자령·오행·역할·새 발견·목표/성어 재료 여부를 5×2 결과판으로 유지 표시
- 10연 소환은 10웨이브에 개방되고 현재부터 10회분의 단계별 소환 비용을 정확히 합산하며, 전장의 남은 칸을 먼저 채운 뒤 초과 자령은 수량 제한 없는 스택형 런 인벤토리에 보관
- 기본 적 이동속도를 약 27% 낮추고 자령의 역할별 기본 공격 주기를 약 35~42% 늘려 80기 전투에서도 공격과 능력 발동을 읽을 수 있게 조정
- 순환형 경로에서 사거리 이탈과 딜로스를 만들던 적 후퇴 효과를 제거하고, 산맥·이동 뜻 능력을 제자리 봉쇄와 강한 감속으로 교체
- 독립 `강화` 탭에서 엽전 공용 강화와 오행 문기 강화를 각각 5능력치×99단계까지 `1회·5회·최대` 투자하고, 분해 점수 5·15·30에 열리는 오행별 고유 특성 3종을 각각 10단계까지 강화
- 핵심 행동의 `자동배치`는 런 인벤토리 자령을 빈칸에 먼저 투입하고, 현재 완성 가능한 사자성어를 봉인한 뒤 다섯 오행진의 공명 단계가 최대가 되도록 재배치
- 같은 오행 자령이 16기를 넘으면 공격 기댓값이 높은 16기를 해당 오행진에 우선 배치하며, 런 인벤토리 자령은 빈 전장 칸 수만큼 먼저 투입
- 은행 이자는 매 웨이브 종료 시 현재 보유 엽전 20개당 1엽전, 최대 20엽전을 지급하며, 정상 방어는 기본 웨이브 보상을 더한 뒤 계산
- 잔존 적이 순환 중인 채 다음 웨이브가 합류해도 턴 전환 이자를 정확히 한 번 지급하고, 최초 1웨이브 시작 전에는 지급하지 않음
- 우측 `인벤` 탭은 같은 한자를 `木 ×4`처럼 묶어 표시. 자령 카드를 선택해 빈 칸을 누르면 배치하고 찬 칸을 누르면 기존 자령을 인벤토리로 보내며 한 번에 교체
- 판매는 엽전을, 독립 `강화` 탭의 일괄 분해는 해당 오행 문기와 단계별 분해 점수를 지급. 잠금·유일 보유·목표·성어·합성·농축 투자·오행진 4/8/12/16 임계치를 기본 보호하며 실행 직전에 다시 검증
- 독립 `농축` 탭에서 동일 한자 중복 1기 또는 같은 오행 문기 4·6·8을 직접 선택한다. 자령마다 최대 `濃 3`이며 농축 방향은 자령의 역할이 정한다(연사·지원은 공속 +7.5%/濃, 나머지는 피해 +12%/濃). 실행 전에 공격력·초당 공격·사거리·기술 효과를 비교
- 런 인벤토리 자령은 공격·오행진 공명·사자성어에는 참여하지 않지만 합성 재료로 사용할 수 있고, 모든 재료가 인벤토리에 있으면 결과도 인벤토리에 보관
- 통합 자령 도감은 별 등급과 `독립` 여부를 별개의 표식으로 보여 준다. 별은 전투 등급이 아니라 직접 소환 재료부터 결과까지 필요한 가장 긴 선행 조합 수순으로 계산
- 조합 가능한 1단은 기본 공격만 사용하고 2단부터 의미·역할 기술을 해금. 의미 기술은 목=가시뿌리밭, 화=용암화염지대, 토=유사진흙지대, 금=쇠압정지대, 수=비구름냉우의 저자극 지속 장판을 적 경로에 남김
- 공격 적중 시 전장 전체에 적용되던 밝기 필터를 제거하고, 적의 흰색 점멸은 작은 먹색 충격 테두리로 교체. 투사체도 흰 섬광 대신 낮은 광량의 오행색 국소 피드백 사용
- 수진·금진·토진·목진·화진마다 해당 오행 자령이 4·8·12·16기에 도달하면 그 진의 피해가 +6%·+12%·+18%·+25%로 증가
- 이웃한 4칸에 글자를 순서대로 배치하면 즉시 자동 봉인되는 사자성어 진법
- 기존 이심전심·백발백중·온고지신·유구무언에 천자문 원문 첫 100개 사언 성구를 더한 한국 성어 도감 104개
- 천자문 1구 `天地玄黃`부터 100구 `逐物意移`까지 원문 순서·표준 독음·짧은 뜻·전투 효과를 수록
- 한국 런은 시드별 성구 5개만 선정하고 현재 목표 1개의 직접 재료만 소환 풀에 추가해 한자 노출과 전투 밀도를 함께 유지
- 피해·사거리·감속·합성 엽전의 네 효과 계열을 고르게 선정하고, 계열별 누적 상한으로 중복 효과 폭주 방지
- 일본·중국 모드는 기존 4개 성어의 신자체/간체 변형과 런 영구 보너스를 유지
- 1280×720 기준 전장·조작 패널·도감 글자 크기와 정보 위계를 전면 확대
- 16:9 데스크톱은 화면에 맞춰 선명하게 확대하고, 좁은 화면은 전장과 패널을 세로 배치해 글씨 크기 보존
- 우측 정보는 자령·합성·성어·도감·기록 탭으로 단계화하고 소환·합성을 1차 행동으로 강조
- 성어 목표와 자동 발동 결과를 우측 성어 탭에 모아 전장 상·하단 오버레이 제거
- 자령 모드 전장에는 한자·훈음, 공부 모드 전장에는 큰 한자·짧은 읽기, 선택 카드·목표·도감에는 자세한 훈음/음독·훈독/병음과 뜻 표시
- 전략 조합전은 실제 한자 조합식을 사용하고, 캐주얼 8성전만 별도의 같은 오행·같은 별 3체 승급 규칙을 사용
- 중복 부모 보존: 木 + 木 → 林은 서로 다른 木 타워 두 개를 소비
- 반자동 제안, 선택 기반 수동, 목표 경로 자동의 세 가지 합성 방식
- 목표 재료 약가중치·12/30회 계보 확정과 소프트 천장, 10·25·45·65·85웨이브에 순차 개방되는 0~5단계 인연 연구

## 데이터 상태

공개 저장소의 `handoff_source`에는 실행에 필요한 압축 매니페스트와 지역별 `*.runtime.json`만 포함합니다. 원본 인수 문서·검토표·로컬 경로 정보는 공개하지 않습니다. 언어 데이터의 내부 검토 상태는 제작 근거 보존용이며 게임 UI에는 노출하지 않습니다. 천자문 전투 데이터는 `src/data/cheonjamun-runtime-jaryeongs.json`, 플레이어 도감 데이터는 `src/data/cheonjamun-jaryeong-dex-v1.json`에 별도 보존하며, 읽기·부수 데이터의 출처와 이용 조건은 `THIRD_PARTY_NOTICES.md`를 확인하세요. 프로젝트 전용 그래픽의 이용 경계는 `ASSET_RIGHTS.md`에 명시했습니다.

읽기 사전은 Unicode 17.0.0 Unihan의 `kHangul`, `kJapanese`, `kMandarin`, `kDefinition`과 BSD-3-Clause libhangul의 한국어 훈음 사전에서 생성했습니다. 세 지역 6,636개 레코드의 중복을 합친 4,560개 글리프 모두에 학습 항목이 있고, 그중 3,050자는 libhangul 훈음이 연결됩니다. 한국 천자문은 사전 훈음 976자와 프로젝트 교정 24자를 합쳐 1,000/1,000자 모두 훈음을 표시합니다. 일본·중국은 각각 2,136/2,136, 3,500/3,500자에 지역 읽기가 있습니다. 한국어 훈이 없는 다른 희귀 글자는 영어 정의를 `뜻(영)`으로 명확히 구분합니다. 재생성 명령은 `npm.cmd run generate:learning -- <Unihan_Readings.txt 경로> <libhangul hanja.txt 경로>`이며 고정 커밋·해시·이용 조건은 `THIRD_PARTY_NOTICES.md`에 기록했습니다.

한국 도감의 쉬운 뜻풀이는 국립국어원 한국어기초사전 2026-08-19 JSON 배포본의 학습자용 정의를 바탕으로, 동음이의어·옛 훈·지나치게 짧은 뜻 300여 자를 글자별 문장으로 교정해 만들었습니다. 천자문 1,000자와 보충 `烈`까지 1,001/1,001자 모두 전용 풀이가 있으며 일반 기본 문장으로 대체되는 글자는 없습니다. 런타임 데이터는 `src/data/korean-easy-meanings.json`, 교정 원본은 `src/data/korean-easy-meaning-overrides.json`, 생성기는 `scripts/build-korean-easy-meanings.mjs`에 보존합니다.

부수 사전은 같은 Unicode 17.0.0 Unihan의 `Unihan_IRGSources.txt` 내 `kRSUnicode`에서 생성했고, 지역 중복을 합친 4,560/4,560자 전부에 강희자전 214부수 번호가 연결됩니다. 캐주얼 기본 별도 같은 파일의 `kTotalStrokes`에서 생성하며 입력 SHA-256과 1,000자 피라미드 분포를 생성 단계에서 검증합니다. 재생성 명령은 각각 `npm.cmd run generate:radicals -- <Unihan_IRGSources.txt 경로>`, `npm.cmd run generate:strokes -- <Unihan_IRGSources.txt 경로>`입니다.
