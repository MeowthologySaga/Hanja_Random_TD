# 한자 운명진 v0.27

한국·일본·중국의 실제 지역별 한자 조합식을 사용해 자령을 합성하는 20웨이브 랜덤 타워 디펜스입니다. 기존 v0.1과 원본 핸드오프 ZIP을 덮어쓰지 않은 별도 Git 프로젝트입니다.

## 바로 실행

Windows 로컬 핸드오프에 `개발서버_실행.exe`가 포함되어 있다면 더블클릭합니다. 공개 소스 저장소에는 생성된 EXE를 넣지 않으므로 아래 명령으로 실행하거나 런처 소스를 직접 빌드합니다. 서버가 이미 실행 중이면 런처는 중복으로 띄우지 않고 브라우저만 엽니다.

런처 소스는 `tools/dev-server-launcher/Program.cs`에 있으며 `tools/dev-server-launcher/build.ps1`로 단일 EXE를 다시 만들 수 있습니다. 로컬 생성 파일이라 코드 서명은 포함하지 않았습니다.

명령줄로 실행하려면:

~~~powershell
npm.cmd ci
npm.cmd run dev
~~~

브라우저에서 http://127.0.0.1:4437/ 을 엽니다.

## 이번 버전의 핵심

- KR 원본 1,000자와 천자문 누락 보충 `烈` 1자, JP 2,136자, CN 3,500자를 지역 ID로 분리
- 기본 전장은 기존 자령 30종과 승인된 천자문 자령 50종, 총 80개의 2×2 전투 시트를 사용하는 `자령 모드`
- 천자문 의미와 기존 오행이 충돌한 18자는 원본 JSON을 보존한 채 KR 전용 의미 기반 타입 오버레이 적용
- 첫 4회는 목표·사자성어 온보딩용 기존 가중치를 유지하고, 5회째부터 신규 직접 자령을 동등 편성해 미발견 한자를 우선하는 중복 억제 가중치 적용
- 정확히 대응하는 한자는 해당 자령을, 나머지 글자는 같은 오행의 기존 자령 중 하나를 결정론적으로 배정
- 자령 머리 위와 선택 카드에 현재 한자와 짧은 훈음을 표시하고, 부수는 공부 모드·도감에 유지
- 설정의 `공부 모드`로 전환하면 v0.7의 큰 한자 원형과 짧은 읽기 표시를 그대로 사용하며 선택은 브라우저에 저장
- 북·서·중앙·동·남에 정확한 4×4 오행진 5개를 배치해 총 80칸을 전부 사용
- 따뜻한 한지 바탕 위에 다섯 진과 먹빛 경로를 동일한 200×200 정사각형 모듈로 맞추고, `바깥 십자 외곽 1바퀴 → 중앙 정사각형 1바퀴`의 규칙적인 이중 사각 순환 사용
- 경로의 각 직선 중앙에는 붓끝형 겹화살표를 고정하고, 젖은 먹방울 10개와 번짐 꼬리가 같은 방향으로 반복 순환해 다음 이동 구간을 예측 가능
- 한지 바탕은 정적 CSS 합성 레이어에 고정하고 지도만 독립적으로 확대·축소·패닝해 프레임별 재표본화 깜박임과 최소 72% 축소의 검은 빈 공간을 함께 방지
- 북·서·중앙·동·남 오행진은 옅은 수묵·담채 카드로 정리하고 네 출구는 주홍색 `出` 인장으로 표시
- 북·동·남·서 네 출구가 같은 단일 순환로를 공유하며 새 적은 네 출구에서 차례대로 균등 출현
- 적은 한 바퀴 뒤 사라지거나 결계를 깎지 않고 처치될 때까지 계속 순환하며, 활성 적 80체 또는 보스 제한시간 초과만 게임오버 조건으로 사용
- 일반 웨이브는 마지막 적 소환 후 16초 카운트다운이 끝나면 잔존 적을 유지한 채 다음 웨이브가 합류해 미처리 적 누적 자체가 패널티로 작동
- 전장 기본 배율 115%, 휠 확대·축소 72%~260%, 휠 클릭 드래그 패닝, 확대 상태 선택·드래그 좌표 보정, 왼쪽 아래 115% 중앙 초기화 버튼 제공
- 자령 머리 위 라벨 높이와 한자·훈음 글자 크기를 키워 기본 배율에서도 획이 뭉개지거나 읽기가 잘리지 않도록 보강
- 우측 상단에서 1×·2×·3× 게임 배속 순환
- 설정의 `뽑기 후 자동 배치`는 기본 ON이며, OFF일 때 새 자령을 이번 판 전용 대기 인벤토리에 보관. 자동 배치가 켜져 있어도 전장 80칸이 차면 소환을 계속 허용하고 새 자령을 런 인벤토리에 자동 보관
- 전장 완성 뒤에는 균형·탐색·계보·농축 목적 소환을 선택할 수 있으며, 10연 마지막 결과는 가능한 경우 미발견 한자·목표 재료·보유 중복 중 선택한 목적을 보장
- 단일 소환은 3.8초간 큰 결과 카드를 표시하고 화면 아무 곳을 누르면 즉시 닫힘. 소환·탭 버튼을 눌렀다면 결과창을 닫는 동시에 해당 조작도 이어서 실행. 10연 소환은 한자·훈음·자령·오행·역할·새 발견·목표/성어 재료 여부를 5×2 결과판으로 유지 표시
- 10연 소환은 현재부터 10회분의 단계별 소환 비용을 정확히 합산하며, 전장의 남은 칸을 먼저 채운 뒤 초과 자령은 수량 제한 없는 스택형 런 인벤토리에 보관
- 기본 적 이동속도를 약 27% 낮추고 자령의 역할별 기본 공격 주기를 약 35~42% 늘려 80기 전투에서도 공격과 능력 발동을 읽을 수 있게 조정
- 순환형 경로에서 사거리 이탈과 딜로스를 만들던 적 후퇴 효과를 제거하고, 산맥·이동 뜻 능력을 제자리 봉쇄와 강한 감속으로 교체
- 엽전으로 모든 자령의 공격력·공격 속도·사거리·능력 위력·효과 지속을, 분해로 얻는 각 오행 문기로 해당 오행의 같은 다섯 능력치를 각각 99단계까지 반복 강화
- 핵심 행동의 `자동배치`는 전장에 있는 자령만 사용해 현재 완성 가능한 사자성어를 먼저 봉인하고, 이후 다섯 오행진의 공명 단계가 최대가 되도록 재배치
- 같은 오행 자령이 16기를 넘으면 공격 기댓값이 높은 16기를 해당 오행진에 우선 배치하며, 런 인벤토리 자령은 사용자의 배치 의도를 보존하기 위해 자동으로 꺼내지 않음
- 은행 이자는 매 웨이브 종료 시 현재 보유 엽전 10개당 1엽전을 제한 없이 지급하며, 정상 방어는 기본 웨이브 보상을 더한 뒤 계산
- 잔존 적이 순환 중인 채 다음 웨이브가 합류해도 턴 전환 이자를 정확히 한 번 지급하고, 최초 1웨이브 시작 전에는 지급하지 않음
- 우측 `인벤` 탭은 같은 한자를 `木 ×4`처럼 묶어 표시. 자령 카드를 선택해 빈 칸을 누르면 배치하고 찬 칸을 누르면 기존 자령을 인벤토리로 보내며 한 번에 교체
- 판매는 엽전을, 분해는 해당 오행 문기를 지급. 보호 규칙 기반 정리 후보는 잠금·유일 보유·미완성 성어·현재 합성·오행진 4/8/12/16 임계치를 건드리지 않으며 확인 후 인벤토리 후보만 일괄 분해
- 동일 한자 중복을 우선 소비하고 부족하면 같은 오행 문기를 사용하는 `문기 농축` 추가. 자령마다 최대 `濃 3`이며 연속 농축은 공격 속도, 심화 농축은 피해와 의미 능력을 강화
- 런 인벤토리 자령은 공격·오행진 공명·사자성어에는 참여하지 않지만 합성 재료로 사용할 수 있고, 모든 재료가 인벤토리에 있으면 결과도 인벤토리에 보관
- 도감의 전체 한자·보유 자령·조합표를 `직접 소환·1단 합성·2단 합성…`으로 분류하며 각 단계의 지역별 수량을 표시. 단계는 전투 등급이 아니라 직접 소환 재료부터 결과까지 필요한 가장 긴 선행 합성 횟수로 계산
- 공격 적중 시 전장 전체에 적용되던 밝기 필터를 제거하고, 적의 흰색 점멸은 작은 먹색 충격 테두리로 교체. 투사체도 흰 섬광 대신 낮은 광량의 오행색 국소 피드백 사용
- 수진·금진·토진·목진·화진마다 해당 오행 자령이 4·8·12·16기에 도달하면 그 진의 피해가 +6%·+12%·+18%·+25%로 증가
- 이웃한 4칸에 글자를 순서대로 배치하면 즉시 자동 봉인되는 사자성어 진법
- 기존 이심전심·백발백중·온고지신·유구무언에 천자문 원문 첫 100개 사언 성구를 더한 한국 성어 도감 104개
- 천자문 1구 `天地玄黃`부터 100구 `逐物意移`까지 원문 순서·표준 독음·짧은 뜻·전투 효과를 수록
- 한국 런은 시드별 성구 5개만 선정하고 현재 목표 1개의 직접 재료만 소환 풀에 추가해 한자 노출과 전투 밀도를 함께 유지
- 피해·사거리·감속·합성 엽전의 네 효과 계열을 고르게 선정하고, 계열별 누적 상한으로 중복 효과 폭주 방지
- 일본·중국 모드는 기존 4개 성어의 신자체/간체 변형과 런 영구 보너스를 유지
- 1280×720 기준 전장·조작 패널·도감 글자 크기와 정보 위계를 전면 확대
- 16:9 데스크톱은 화면에 맞춰 선명하게 확대하고, 좁은 화면은 전장과 패널을 세로 배치해 글씨 크기 보존
- 우측 정보는 자령·합성·성어·도감·기록 탭으로 단계화하고 소환·합성을 1차 행동으로 강조
- 성어 목표와 자동 발동 결과를 우측 성어 탭에 모아 전장 상·하단 오버레이 제거
- 자령 모드 전장에는 한자·훈음, 공부 모드 전장에는 큰 한자·짧은 읽기, 선택 카드·목표·도감에는 자세한 훈음/음독·훈독/병음과 뜻 표시
- 같은 등급 3체 합성을 제거하고 실제 한자 조합식 합성으로 교체
- 중복 부모 보존: 木 + 木 → 林은 서로 다른 木 타워 두 개를 소비
- 반자동 제안, 선택 기반 수동, 목표 경로 자동의 세 가지 합성 방식
- 목표 재료 약가중치와 소프트 천장, 0~5단계 인연 연구
- 오행 상생과 웨이브 약점, 기존 자령 시트로 구분되는 장갑·질풍·군집·회생·보스 적
- 연결성이 높은 허브 글자의 전투 예산 감산과 막다른 글자의 보상
- 오행 5종 × 뜻 계열 12종 × 조준 우선순위 6종 × 전투 역할 6종 × 조합망 역할 4종 × 부모 계승 × 성장·농축 단계의 합성 능력표
- 눈·문·천후·산맥·언어·이동·생장·화염·금속·마음·재화 뜻 계열에 따라 강적·최고속·장갑·밀집·고가치 적을 다르게 조준하고 전이·후퇴·광역·가속·현상금 등 서로 다른 행동을 수행
- 역할 기술 충전 링, 타워 머리 위 짧은 능력 팝업·전투 피드·적 상태 문양·연쇄 처치 피드백
- 빈번한 발동은 타워별 0.45초 표시 제한으로 겹침을 줄이고, 기록 탭에는 `이동 봉쇄 0.5초`, `주변 1체에 41% 피해`, `엽전 +1`처럼 실제 대상·수치를 유지
- 합성 카드와 완성 연출에서 새 역할 기술·재료 계승 능력을 즉시 공개
- 선택 자령의 `파생 합성` 서랍에 가능한 결과 스프라이트·구성식을 표시하고, 재료가 모두 있으면 컬러·부족하면 회색으로 구분
- 파생 결과에 커서를 올리면 해당 합성에 쓰일 전장 자령을 금색 연결선과 표식으로 강조하고, 전장·런 인벤토리 재료를 함께 판정
- 합성 카드에 완성될 자령 스프라이트를 미리 표시
- 자령 잠금으로 합성 재료 소비·판매를 막고, 전투 기능과 재배치는 그대로 유지
- 소환·합성으로 획득한 지역별 자령 종류와 횟수를 브라우저에 자동 저장하는 영구 `보유 자령` 도감
- 전체 한자·보유 자령·조합표·사자성어의 4개 전략 탭과 공격·사거리·공속·능력 설명·획득 단계를 갖춘 도감
- 전장에 적이 80체 쌓이거나 10/20웨이브 보스를 각각 60/85초 안에 처치하지 못하면 즉시 패배
- 네 출구에서 골고루 소환되며, 일반 웨이브는 잔존 적이 있어도 소환 완료 16초 뒤 다음 병력이 합류
- 검색 가능한 지역 도감, 목표 변경, 발견 상태, 검토 대상 표시
- 결정론 시드, 재도전, 키보드 단축키, Web Audio 효과음

## 데이터 상태

공개 저장소의 `handoff_source`에는 실행에 필요한 압축 매니페스트와 지역별 `*.runtime.json`만 포함합니다. 원본 인수 문서·검토표·로컬 경로 정보는 공개하지 않습니다. 런타임은 초벌 데이터를 사용하며 `needsReview` 항목은 언어학적 최종 확정이 아닙니다. 현재 검토 대상은 KR 800, JP 1,544, CN 1,455자입니다. 천자문 자령 데이터는 `src/data/cheonjamun-jaryeongs.json`에 별도 보존하며, 읽기·부수 데이터의 출처와 이용 조건은 `THIRD_PARTY_NOTICES.md`를 확인하세요. 프로젝트 전용 그래픽의 이용 경계는 `ASSET_RIGHTS.md`에 명시했습니다.

읽기 사전은 Unicode 17.0.0 Unihan의 `kHangul`, `kJapanese`, `kMandarin`, `kDefinition`과 BSD-3-Clause libhangul의 한국어 훈음 사전에서 생성했습니다. 세 지역 6,636개 레코드의 중복을 합친 4,560개 글리프 모두에 학습 항목이 있고, 그중 3,050자는 libhangul 훈음이 연결됩니다. 한국 천자문은 사전 훈음 976자와 프로젝트 교정 24자를 합쳐 1,000/1,000자 모두 훈음을 표시합니다. 일본·중국은 각각 2,136/2,136, 3,500/3,500자에 지역 읽기가 있습니다. 한국어 훈이 없는 다른 희귀 글자는 영어 정의를 `뜻(영)`으로 명확히 구분합니다. 재생성 명령은 `npm.cmd run generate:learning -- <Unihan_Readings.txt 경로> <libhangul hanja.txt 경로>`이며 고정 커밋·해시·이용 조건은 `THIRD_PARTY_NOTICES.md`에 기록했습니다.

부수 사전은 같은 Unicode 17.0.0 Unihan의 `Unihan_IRGSources.txt` 내 `kRSUnicode`에서 생성했고, 지역 중복을 합친 4,560/4,560자 전부에 강희자전 214부수 번호가 연결됩니다. 재생성 명령은 `npm.cmd run generate:radicals -- <Unihan_IRGSources.txt 경로>`입니다.

## 독자화 경계

이 프로젝트는 랜덤 타워 디펜스 장르의 플레이 감각만 참고합니다. 스타크래프트, 메이플스토리, 메이플 운빨 디펜스의 코드·맵·명칭·이미지·사운드를 포함하지 않습니다. 자령 PNG는 사용자가 보유한 기존 30종과 별도 승인한 천자문 50종만 사용하며, 나머지 전장 그래픽은 Canvas/CSS, 효과음은 Web Audio로 구성합니다.
