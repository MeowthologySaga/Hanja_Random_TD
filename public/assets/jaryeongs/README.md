# 기존 자령 스프라이트 재사용

이 폴더의 30개 `sheet-transparent.png`는 동일 저장소군의 `jaryeong-rogue-lab` 자령 도감 원본을 변경 없이 복사한 런타임 자산이다.

- 형식: 투명 PNG, 2×2 전투 프레임
- 런타임 사용: 기본 자령 모드는 대기 프레임과 공격 프레임을 상황에 따라 선택한다.
- 대응 원칙: 한자가 정확히 맞으면 해당 자령을 사용한다. 미대응 글자는 같은 오행의 기존 자령 중 크고 직립한 실루엣을 가진 기본군에서 글자 해시로 고정 배정하며, 가로로 긴 특수 개체는 정확히 대응할 때만 사용한다.
- 추가 생성 이미지나 코드 도형 대체물은 포함하지 않는다.
